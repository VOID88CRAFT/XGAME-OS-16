# XGAME OS 16 Launcher v0.3

این پروژه یک پوستهٔ اندرویدی (Launcher shell) است که رابط HTML را داخل WebView اجرا می‌کند؛ سیستم‌عامل مستقل یا رام اندروید نیست.

## ساخت APK با GitHub Actions
1. یک مخزن جدید در GitHub بساز.
2. محتوای این پوشه را در ریشهٔ مخزن بارگذاری کن.
3. وارد زبانهٔ Actions شو و workflow با نام **Build XGAME OS 16 APK** را اجرا کن.
4. پس از اتمام موفق، از بخش Artifacts فایل `XGAME-OS-16-Launcher-v0.3` را دریافت کن و APK داخل آن را نصب کن.

## استفاده به‌عنوان لانچر
پس از نصب، دکمهٔ Home را بزن و در صورت نمایش انتخاب‌گر، XGAME OS 16 را انتخاب کن. برای بازگشت، از تنظیمات اندروید > برنامه‌ها > برنامه‌های پیش‌فرض > برنامه Home، لانچر قبلی را انتخاب کن (نام مسیر بسته به گوشی فرق دارد).

## محدودیت‌های فعلی
- تنظیمات، مرکز کنترل و آیکون‌های برنامه‌ها فعلاً نمایشی‌اند؛ کلیدهای وای‌فای/بلوتوث/حالت پرواز تنظیمات واقعی گوشی را تغییر نمی‌دهند.
- WebView معمولاً به درصد باتری از Battery Status API دسترسی تضمین‌شده ندارد؛ اگر پشتیبانی نشود، مقدار به‌روزرسانی نمی‌شود.
- وضعیت واقعی آنتن و وای‌فای در HTML فعلی نمایش داده نمی‌شود؛ شکل آن‌ها فعلاً تزئینی است.
- برای اجرای واقعی برنامه‌ها و اتصال تنظیمات به اندروید، باید در مراحل بعدی کد بومی اندروید و مجوزهای لازم اضافه شود.
- این پروژه فعلاً امضای انتشار (release signing) ندارد؛ خروجی GitHub Actions نسخهٔ debug برای آزمایش است.

## نیازمندی ساخت
Android Gradle Plugin 8.7.3، Gradle 8.9 یا سازگار، JDK 17 و Android SDK Platform 35.
